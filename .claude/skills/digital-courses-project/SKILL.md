# פרויקט הקורסים הדיגיטליים של עדי

עדי (adielbaz14, פנייה בלשון נקבה) בונה ומוכרת קורסים דיגיטליים כתובים בעברית (RTL).

## שני הקורסים

- קהל: מנהלות/י אדמיניסטרציה, רכזי תפעול, VA
- 10 מודולים (`course/00..09-*.md`) + 2 נספחים (`course/templates/`):
  ספריית 25+ פרומפטים, תבנית קטלוג שירותים/SLA
- מבנה מסלול: שינוי תפיסה → מיפוי תהליכים → יסודות AI → מייל → יומן →
  מסמכים → אוטומציות → בק-אופיס כשירות → פרויקט מסכם
- תמחור מוצע: 147 ₪ השקה / 297 ₪ מלא

### 2. "בונים מערכות CRM לעסקים — עם Zoho"
- קהל: מתחילים ללא רקע טכני שרוצים מקצוע דיגיטלי (בוני מערכות CRM כשירות)
- מבוסס על סילבוס "The CRM Architect" של Hiltech שעדי סיפקה מהדרייב,
  בתוספת: מכירת המערכת, הטמעה בבית העסק ושירותי המשך
- 11 מודולים (`crm-course/00..10-*.md`) + 4 נספחים (`crm-course/templates/`):
  בנק 50+ שאלות אפיון, תבנית מסמך אפיון, צ'קליסט מסירה, תבנית הצעת מחיר לשירות
- מבנה מסלול: הבנת עסק ומציאת כאב → פגישת אפיון → יסודות Zoho → בנייה →
  יבוא נתונים → עבודה יומיומית → הצעות מחיר וחתימות → דשבורדים ומסירה →
  מכירה והטמעה → ריטיינר ושירותי המשך + פרויקט מסכם
- עקרון פדגוגי: "עסק מלווה" — הלומד בוחר עסק אמיתי במודול 0 ובונה לו מערכת לאורך הקורס

## עדי לומדת את קורס ה-CRM! (מסלול למידה פעיל)

עדי לומדת את קורס ה-CRM עם קלוד כמורה פרטית, כאן בפרויקט. שיחת לימוד = מפגש.
כשעדי אומרת "בואי נמשיך ללמוד" — לפתוח את המודול הבא, ללמד בקצב שלה, צעד-צעד.
- **עסק מלווה:** אלבז ציון — מקלחונים ומראות (העסק המשפחתי; יש גם סקיל elbaz-quote)
- **מהאפיון הראשוני (מודול 0):** מוכרים בעיקר מקלחונים ומראות (לעיתים מעקות
  זכוכית לבריכה ודלתות הזזה); לקוחות: פרטיים בעיקר + קבלנים ומעצבי פנים;
  מקור לידים עיקרי: פה לאוזן
- **הושלם:** מודולים 0–1 (23.7.2026) · **הבא בתור:** מודול 2 — פגישת האפיון
- **3 השערות הכאב שעדי כתבה על אלבז ציון (מודול 1):**
  1. מפסיד כסף בהצעות מחיר שלא נסגרות — אין תזכורת לחזור ללקוחות (ציון "עלול לשכוח")
  2. מפסיד הכנסות חוזרות — אין היסטוריה על לקוחות מלפני שנים
  3. אין תמונת מצב של הצעות פתוחות — אי אפשר לדעת איך ייראה החודש הבא
- מצב קיים בעסק: כל המידע בראש של ציון ובוואטסאפ; מדידה בבית הלקוח היא שלב
  ייחודי במסע הלקוח שלו; קבלנים/מעצבי פנים = מקורות הפניה שלא מתועדים
- הערה חשובה: Payhip בהמתנה עד שעדי מדברת עם רואה חשבון (עוסק/מיסוי)

**השלבים הבאים (טרם בוצעו):**
1. עדי מקימה חשבון Payhip ומעלה את ה-ZIPים (ללוות אותה צעד-צעד!)
2. התאמת דפי המכירה לפלטפורמה
3. רעיונות שהוצעו: ליד-מגנט (מודול 1 של הבק-אופיס בחינם / בנק שאלות האפיון של
   ה-CRM בחינם תמורת מייל), חבילת שני הקורסים בהנחה (קרוס-סייל), מיתוג אישי
   על השערים, Order Bump ("ביקורת אפיון אישית"), ובהמשך פלטפורמת קורסים עם לוגין

## איך בונים מחדש את קבצי המוצר

כשמעדכנים תוכן: לערוך את קבצי ה-md → להריץ את סקריפט הבנייה → להחליף ב-dist/.

1. תלויות (בסביבת הענן): `pip install markdown` + `apt-get install -y fonts-noto-core`
   (חובה לפונט עברי, אחרת ה-PDF יוצא ג'יבריש)
2. סקריפט מוכן לקורס ה-CRM: `scripts/build_crm_course.py` (מצורף לסקיל הזה) —
   ממיר את כל ה-md לקובץ HTML יחיד: python-markdown (extensions: tables,
   fenced_code, sane_lists), ממפה קישורי .md לעוגנים, מסיר שורות ניווט
   הקודם/הבא/חזרה, ממיר `- [ ]` ל-☐, מוסיף שער + תוכן עניינים + CSS של RTL.
   לקורס הבק-אופיס: אותו עיקרון — להתאים את רשימת FILES ואת פרטי השער.
3. PDF: `/opt/pw-browsers/chromium --headless --no-sandbox --disable-gpu
   --print-to-pdf=dist/<name>.pdf --no-pdf-header-footer dist/<name>.html`
4. בדיקת איכות לפני מסירה: לרנדר עמודים מה-PDF ולוודא — שער קריא (כותרת
   לבנה על רקע כהה!), עברית RTL תקינה, טבלאות, צ'קבוקסים
5. חבילת ZIP למכירה: `קורס-<שם>.pdf` + `קורס-<שם>.html` + `קרא-אותי.txt`
   (תודה על הרכישה, מה בחבילה, איך ללמוד, מה להכין)
